# zstd 辞書の扱い

Bombe は圧縮に専用の zstd 辞書を使う。圧縮形式のルールを展開するには同じ辞書が必要になる。

## 方針

出所を検証できる形で、人が読めるソースファイルとしてリポジトリに載せる。バイナリファイルは置かない。

## リポジトリに載せるもの

| 載せるもの | 役割 |
| --- | --- |
| Bombe のコミット番号 | 抽出スクリプト内の定数。どの版から取ったかの記録 |
| 抽出スクリプト | コミット番号を固定した URL から `Compress.cpp` を取得し、`dictionary` 配列を抜き出して、辞書のソースファイルを生成する |
| 生成された辞書のソースファイル | ツール本体が読み込む。手では編集しない |
| 一致を確かめるテスト | 生成物のハッシュが期待値と一致するかを検査する |

## 生成するソースファイルの形

- 先頭に、取得元の URL、コミット番号、生成スクリプトの名前、ライセンスをコメントで書く
- 辞書の先頭にある zstd 用の統計表は数値の配列で書く
- 残りは文字列として書き、文字で表せないバイトだけエスケープにする
- 実行時に 1 本のバイト列へ組み立てて zstd ライブラリに渡す

## 辞書の中身

- 全体で 7157 バイト。先頭 4 バイトは zstd の辞書形式を示す識別子（`37 a4 30 ec`）
- 7157 バイト中 7084 バイトが普通の文字。先頭の数十バイトが統計表で、残りはルールやレベルの JSON の断片
