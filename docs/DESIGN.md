# 実装の方針

プロジェクト全体の方針は [README](../README.md) を参照。

## 入出力
[FORMAT.md](FORMAT.md) も参照。

- 圧縮形式と平文の両方のparse,printを行う
- `rule` 単体と `rules` 配列の両方を読む
- ゲーム側にあるようなルールの正当性検証は行わない

## Bombe のコードとの関係

- Bombe から参照・準拠するもの:
  - クリップボード形式（点字エンコード、zstd 辞書圧縮）の仕様
  - ルールの JSON スキーマ（フィールド名と値の意味）
  - 展開に必要な zstd 辞書バイナリ（扱いは [DICTIONARY.md](DICTIONARY.md) を参照）
  - (他は参照しない)
- 自前で実装するもの:
  - データモデル
  - UI,ソートなど各種操作
